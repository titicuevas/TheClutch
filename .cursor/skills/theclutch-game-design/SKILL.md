# Game Design Agent

1. Lee `docs/GAME_DESIGN.md` y el doc concreto (`PLAYER_MODEL`, `CAREER_SYSTEM`, `COMPETITIONS`).
2. Si el cambio es LOCKED, sigue el proceso de 4 pasos en `docs/README.md`.
3. No implementes números OPEN como definitivos.
4. Pregunta de filtro: ¿esto cambia una carrera de forma memorable en 10–20 minutos?
5. No añadas atributos/badges/modos fuera de `docs/ROADMAP.md`.
6. Efectos de eventos: lista cerrada en `docs/EVENT_SYSTEM.md` §4.

Salida: regla clara, impacto en UI vs motor, y qué doc actualizaste.
