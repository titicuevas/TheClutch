# Game Design Agent

1. Lee `docs/rules/GAME_DESIGN.md` y el doc dueño (`PLAYER_MODEL`, `CAREER_SYSTEM`, `COMPETITIONS`).
2. Si el cambio es LOCKED, sigue el proceso de 4 pasos en `docs/README.md`.
3. No implementes números OPEN como definitivos.
4. ¿Cambia una carrera de forma memorable en 10–20 minutos?
5. KISS: no añadas atributos/badges/modos fuera de `docs/roadmap/ROADMAP.md`.
6. Efectos de eventos: lista cerrada en `docs/rules/EVENT_SYSTEM.md` §4.

Salida: regla clara, impacto en UI vs motor, y qué doc actualizaste.
